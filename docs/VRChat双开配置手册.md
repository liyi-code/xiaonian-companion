# VRChat 双开配置手册（你 + 小念同屏）

> 目标形态：你的账号戴头显（PC VR 串流），小念的账号跑桌面模式，两个人在同一个世界里，
> 她由本机 `src/osc_bridge.py` 驱动：能说话（TTS→VB-CABLE→她的麦克风）、有口型、
> 有表情手势、会记住你教她的动作。

## 一、组件清单

| 组件 | 用途 | 备注 |
|---|---|---|
| VRChat 账号 ×2 | 你 + 她 | 各自登录两个实例 |
| 小念化身 | 她实例穿戴 | 由 VRM 转制，见《小念化身预置清单》 |
| VB-CABLE | TTS 声音 → 她实例麦克风 | 免费版够用（一次一通道） |
| `src/osc_bridge.py` | 双端口 OSC 桥 + 教学引擎 | `pip install python-osc` |
| GPT-SoVITS | 她的声音 | 已在跑，无需改动 |

## 二、OSC 端口设置（防冲突的关键）

两个实例必须错开端口。两个实例都按此设置（**VRChat 启动器长按 Shift 启动实例**，或直接开两个客户端）：

| 实例 | OSC 输出 | OSC 输入 | 说明 |
|---|---|---|---|
| 你（VR 串流） | **9011** | 9000 | 9001 输出默认，改为 9011 |
| 她（桌面模式） | 9012 | **9010** | 9001 默认，改为 9012 |

设置位置：VRChat 内 → 快捷菜单 → Settings → OSC → Enabled 打开 → 修改 Input/Output 端口 → 重启实例生效。
`osc_bridge.py` 默认读 9011、写 9010，与 `.env` 的 `OSC_IN_PORT`/`OSC_OUT_PORT` 一致，可改。

## 三、她的"嘴"与"耳朵"

1. **嘴（TTS → 她的麦克风）**：
   - 安装 VB-CABLE 后，系统里出现 "CABLE Input (VB-Audio Virtual Cable)"；
   - `.env` 设置 `TTS_OUTPUT_DEVICE=CABLE Input (VB-Audio Virtual Cable)`；
   - 她实例里：Settings → 麦克风 选择 "CABLE Output"；
   - 验证：跑 `.\venv\Scripts\python.exe -m src.osc_bridge`，控制台打字让它说话，房间里的人应能听到。
2. **耳朵（你的麦克风共享）**：
   - Windows 声音设置里确保你的实体麦克风"允许应用独占"**取消勾选**（共享模式）；
   - 你的 VRChat 实例用它说话，`osc_bridge` 的 faster-whisper 同时用它听你说话，互不干扰。

## 四、启动顺序

```
1. 退出向日葵/远控（虚拟显示器会导致 VR 黑屏）
2. 切模型：Ollama 用 qwen2.5:7b（显存预算见下）
3. GPT-SoVITS 服务（如果要用她的声音）
4. .\venv\Scripts\python.exe -m src.osc_bridge     ← 她的脑
5. 启动她实例（桌面模式）→ 穿上小念化身 → 进世界
6. 启动你实例（PC VR 串流）→ 进同一世界
7. 桥终端应打印 [OSC入] 监听 9011 且无报错
```

## 五、显存预算（16GB）

| 项目 | 显存 |
|---|---|
| 你的 VR 实例 | 5~6GB |
| 她的桌面实例 | 2~3GB |
| qwen2.5:7b（VR 期间） | 4.5GB |
| GPT-SoVITS（她说话时瞬时） | 1.5GB |
| **合计** | **约 13~15GB** ✅ |

> 14b 模型 + 双开会顶到 16GB 上限导致掉帧，VR 期间切 7b 即可；Unity 编辑器进 VR 前关闭。

## 六、教学玩法（零门槛上手）

1. 你在她面前**比一个手势**（如 👍），然后说："**我开心的时候你就做这个**"；
2. 她立刻模仿一遍 👍，Chatbox 回复"我学会啦～"；
3. 之后每当她的情绪引擎"开心"过线，她会自动比 👍 并显示"你开心的时候～"。

支持的教法（`src/osc_bridge.py` 内 `parse_teaching`）：

| 你说的话 | 学到的规则 |
|---|---|
| "我开心的时候你就做这个"（比手势） | 情绪 joy>0.5 → 手势 |
| "你难过的时候就做这个" | 她的情绪 sadness>0.5 → 手势 |
| "记住：我说『加油』的时候做这个" | 关键词"加油" → 手势 |
| "以后晚上就比这个" | 时间段 18-23 点 → 手势 |
| "……做个『开心』的表情" | 表情参数 → 表情 |
| "……挥手 / 点头 / 鞠躬" | 预设 emote |

管理：控制台输入 `/skills` 查看她学会的行为；`data/custom_skills.json` 是规则库（带审计）。

## 七、常见问题

- **桥终端没收到你的手势**：你的实例 OSC 输出端口不是 9011，或 Settings→OSC 没开输出。
- **她的 Chatbox 是空的**：她实例 OSC 输入端口不是 9010，或 Chatbox 输入需在安全设置允许 OSC 控制。
- **听不到她说话**：`TTS_OUTPUT_DEVICE` 没指向 CABLE Input；或她实例麦克风没选 CABLE Output。
- **她没反应**：教学需要"手势新鲜（4 秒内）+ 语句含教学词（记住/教我/以后…）"；先 `/skills` 看规则有没有入库。
- **口型不张**：确认她实例 OSC 输入 9010 通；桥终端看有没有 [OSC出] 报错。

# 小念化身预置清单（VRChat 转制 + OSC 参数）

> 目标：把小念做成 VRChat 化身，并预置好 `src/osc_bridge.py` 需要的全部参数，
> 让她的情绪、口型、手势、教学动作都能在身上表现出来。

## 一、转制流程（VRM → VRChat 化身）

1. 安装 **VRChat Creator Companion（VCC）** → 新建 Avatar 项目（Unity 2022.3.x，与 SDK 版本匹配）。
2. 把 `yixuan3.vrm` 导入该 Unity 项目：装 **UniVRM** 包（VRM0 模型用 UniVRM 0.x，VRM1 用 VRM 1.x）→ 直接拖进 Assets。
3. 右键 VRM → 转成 humanoid prefab；给根物体加 **VRC Avatar Descriptor**，把 View Position 设到眼睛高度。
4. 表情：把模型自带的 blendshape 在 **FX 动画层**用"手势触发"做 8 组基础表情（VRChat 教程众多），并导出两个自定义参数（见下）。
5. 检查 **Performance Rank**（建议至少 Good；Very Poor 进不了部分世界）→ Build & Publish 上传。
6. 上传前确认：**模型作者允许再分发/上传**；角色版权与 VRChat 规则自负。

## 二、OSC 参数预置清单（必须，她全靠这些表现）

### 1) 官方内置（无需制作，自动可用）

| 参数 | 地址 | 用途 |
|---|---|---|
| Viseme | `/avatar/parameters/Viseme` (0~14) | 她的口型（桥用 TTS 能量实时写） |
| GestureLeft/Right | `/avatar/parameters/GestureL/R` (0~7) | 她的手势 = 你教她的动作 |
| Voice | `/avatar/parameters/Voice` | （你的实例输出，桥读，可留） |

### 2) 自定义表情参数（**需要在 FX 层做**，名字必须一字不差）

桥会写这些参数（值 0~1）来表现她的情绪：

| 参数名 | 表情 | 建议 blendshape |
|---|---|---|
| `ExprJoy` | 开心 | 微笑/眯眼 |
| `ExprAngry` | 生气 | 皱眉 |
| `ExprSad` | 难过 | 嘴角下压/泪 |
| `ExprCalm` | 平静 | 中性放松 |
| `ExprAnxious` | 不安 | 抿嘴/眼神躲闪 |

做法：FX 层建 5 个 Float 参数（默认 0），每个做一个 1D BlendTree 或直接映射到对应 blendshape，输出到面部的 VRM BlendShape 动画。**参数勾选 Save + 允许同步**（别人也要看到她的表情）。

### 3) Emote 参数（教学引擎"挥手/点头/鞠躬…"用）

- FX 层建 1 个参数 `Emote`（类型 **String**，默认空），允许同步；
- 在 FX 层做 7 个 emote 状态，分别由 `Emote` 字符串值触发：
  `wave`（挥手）、`nod`（点头）、`shake_head`（摇头）、`bow`（鞠躬）、`cheer`（欢呼）、`think`（思考）、`sulk`（生闷气）；
- 桥每次写一次值，动画播完由动画状态机自行回到 Idle（String 参数触发一次即入状态）。

## 三、上传前自检清单

- [ ] 8 组基础表情（官方手势）可用
- [ ] 5 个 Expr* 参数能驱动 blendshape
- [ ] Emote 字符串参数能触发 7 个 emote 动画
- [ ] Viseme 参数正常工作（VRChat 化身都自带口型，通常无需额外做）
- [ ] Performance Rank ≥ Good
- [ ] 模型授权允许上传

## 四、与桥的对应关系

```
osc_bridge.py 写入                        化身侧
─────────────────                        ─────
/avatar/parameters/Viseme          →  口型（官方）
/avatar/parameters/GestureLeft     →  手势（官方，教学动作主体）
/avatar/parameters/Expr*           →  情绪表情（自定义）
/avatar/parameters/Emote           →  emote 动画（自定义）
/chatbox/input                     →  她的字幕（官方 Chatbox）
```

> 你的化身（你自己的账号）**不需要**任何预置——桥只读它的手势/口型参数，官方默认就输出。
> 注意：你的实例要在 VRChat 设置里允许 OSC 输出（Settings→OSC→输出端口 9011）。

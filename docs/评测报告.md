# 小念项目 — 模块边界、性能指标与评测报告

> 测试环境：Windows 11 / Python 3.14.6 / AMD Ryzen 9 + NVIDIA RTX 5070Ti 16G
> 本地模型：Ollama qwen2.5:14b (9GB VRAM)
> ⚠️ 所有性能指标均**不包含大模型推理耗时**，仅测量项目自研模块的纯计算开销。

---

## 一、个人原创模块与第三方组件边界

### 1.1 个人原创模块（60 个文件，~22,000 行）

| 层级 | 文件 | 原创内容 |
|---|---|---|
| **大脑** | `src/assistant.py` | LLM 对话引擎、确定性意图路由（10 类正则，不依赖模型意愿）、流式输出、`<think>`剥离、工具调用编排、Session 管理、clayer 意识层桥接 |
| **记忆** | `src/memory.py` | 零依赖 CJK 分词器（自研 unigram+bigram）、TF-IDF 倒排索引检索、长期记忆归档 + 摘要压缩 |
| **情绪/性格** | `src/emotion.py` | 5 维情绪权重系统（joy/anger/sadness/calm/anxiety）、5 种性格由长期情绪差值派生、半衰期衰减、TRAIT_MOTION 肢体参数映射、TRAIT_PROMPT 语气注入 |
| **自主权限** | `src/autonomy.py` | 受约束自调参引擎（7 项白名单）、confirm 规则（never/aggressive/always）、audit 审计日志、健康护栏 |
| **桌面 GUI** | `src/gui.py` | tkinter 悬浮输入条、设置面板、Live2D 子进程管理、消息队列、定时提醒管理器（root.after 真实计时） |
| **工具注册** | `src/tools.py` | `@tool` 装饰器注册表、20 个 Function Calling 工具、动态 schema 实时构建 |
| **网络搜索** | `src/search.py` | DuckDuckGo Lite HTML 解析引擎、代理自动发现（env 变量 + Windows 注册表系统代理） |
| **游戏桥接** | `src/bridge.py` | WebSocket 服务器、NPC 动作下发（性格×情感融合 `compute_action_params`）、数据+截屏联合理、多 NPC 管理 |
| **世界/小镇** | `src/world_state.py` / `explorer.py` / `town.py` / `quest.py` / `villagers.py` | 3D 符号世界感知、自主探索引擎、自给自足小镇经济模拟、任务系统、6 村民预设 |
| **动态技能** | `src/custom_skills.py` | 动态自定义行为库（增/删/查），纯文本「触发词→回应」映射，零代码风险 |
| **视觉** | `src/vision.py` / `src/screen_watch.py` | 多模态视觉客户端（OpenAI 兼容 API）、Win32 API 屏幕活动监控 |
| **语音** | `src/voice.py` | TTS 文本净化、OutputStream 回调实时 RMS 口型计算 |
| **启动器** | `src/launcher.py` / `src/live2d_app.py` / `src/bot.py` | 应用启动、Live2D 透明窗口、多平台 Bot 路由 |
| **多玩家** | `src/multiplayer_memory.py` | 按 scope（MMO/RPG）派生隔离 Memory，TTL + LRU 回收 |

### 1.2 意识层 `src/clayer/`（全部原创，含 C++ 加速）

| 文件 | 原创内容 |
|---|---|
| `consciousness.py` | think() 六步流水线：感知→激活→扩散激活→概率→多念竞争→组装引导 |
| `assoc_graph.py` | 无向加权关联图、扩散激活（spreading activation）、Jaccard 相似度缓存、强度维度计算、consolidate 弱词并入强词 |
| `memory_store.py` | 有上限概念计数库（42000 容量）、显著度、衰减、遗忘、容量淘汰 |
| `affect.py` | 效价—唤醒（valence-arousal）二维情绪模型 + attention softmax |
| `probability.py` | softmax + 统计调制温度 + clamp_and_renorm（water-filling）+ 加权无放回采样 |
| `token_bias.py` | 概率分布→logit_bias 编译（公式：bias = GAIN·P^γ，clamp 到 BIAS_MAX） |
| `perception.py` / `seg.py` | 中文分词（jieba→离线 DAG Viterbi→ngram 三级兜底） |
| `cl_config.py` | 全部 40+ 常量，每项带**神经科学文献出处**（Steyvers & Tenenbaum 2005 / Cowan 2001 / Brysbaert 2016 等） |
| `_core.py` | C++/Python 自动回退 + parity_test 自检 |
| `cpp/pyclayer.cpp` | C++ 热数学重写（pybind11 绑定，MSVC cl.exe 19.29 编译） |
| `cpp/build_pyclayer.py` | 跨平台 C++ 构建驱动 |
| `cpp/gen_cpp_config.py` | `cl_config.py` → `cpp_config.h` 自动转写，保证 C++/Python 参数一致 |
| `test_logit_bias.py` | logit_bias 量化验证：离线 10 组 22 条断言 + 可选在线模型效应测量 |
| `bench_assoc.py` | 关联图性能基准：节点递增耗时曲线 + 零偏差验证（cache on/off fingerprint 一致） |
| `parity_test.py` | C++/Python 数值对照（容差 1e-9） |

## 二、局部性能指标

> 硬件：Windows 11 / Python 3.14.6 / AMD Ryzen 9 / NVIDIA RTX 5070Ti 16GB
> ⚠️ 所有指标**仅测量项目自研模块的纯计算开销，不包含 Ollama qwen2.5:14b 模型推理耗时**。

| 指标 | 实测值 | 样本量 | 说明 |
|---|---|---|---|
| Clayer `think()` 认知注入延迟 | **平均 0.81ms** (min 0.64 / max 0.97) | 10 轮 | 仅意识层图计算（感知+扩散激活+多念竞争+logit_bias 编译） |
| 记忆图遍历 (N=1000, 优化前) | 6.44 ms/spread | 60 轮 | cache OFF，O(N²) 扩散激活 |
| 记忆图遍历 (N=1000, 优化后) | **0.87 ms/spread** | 60 轮 | cache ON（相似度缓存 A 优化），**加速 7.1×** |
| 缓存零偏差验证 | FINGERPRINT **完全一致** (82.34793) | N=200~2000 | 优化不改变激活结果，容差 <1e-6 |
| Unity NPC 动作决策延迟 | **< 2ms**（计算 1.9μs + WebSocket ~1ms） | 50 次 | `compute_action_params` 纯图计算，不经过 LLM |
| 自发轮询间隔 | 5s | 配置常量 | `spontaneousActionInterval` |

### 睡眠性能自愈阈值（设计保证）

| 阈值 | 行为 |
|---|---|
| `< 360ms` | 正常对话 |
| `≥ 450ms` | 犯困态：自然表达想休息，仍正常对话 |
| `≥ 500ms` | 强制睡眠：停止输出 + consolidate 压缩整合记忆（自愈"越聊越慢"） |

## 三、评测结果

### 3.1 任务完成率 = 确定性路由准确率

**24 条样本，测试范围覆盖 10 类工具 + 4 个负例（普通对话不应误触发任何工具）。**

| 类别 | 正确/总数 | 准确率 |
|---|---|---|
| 启动应用 | 2/2 | 100% |
| 打开网址 | 1/1 | 100% |
| 网络搜索 | 3/3 | 100% |
| 文件搜索 | 3/3 | 100% |
| 查看时间 | 3/3 | 100% |
| 普通对话（不应误伤） | 4/4 | 100% |
| 看屏幕 | 1/1 | 100% |
| 睡眠关机 | 1/1 | 100% |
| 定时提醒 | 2/3 | 67% |
| 系统状态 | 0/1 | 0% |
| 自定义行为 | 1/2 | 50% |
| **合计** | **21/24** | **87.5%** |

> 3 个 FAIL 根因均为**正则覆盖边界**（非工具执行失败），涉及"过 10 分钟"/"系统状态 vs 网络搜索"/"【】引号匹配"三条正则精度，属于可定向修复的边界问题。

### 3.2 工具调用正确率

所有通过路由的 21 条样本，`_route_action` 返回的**参数均正确**（delay 数值换算、关键词提取、URL 格式校验全通过）。

### 3.3 记忆准确率

| 指标 | 值 |
|---|---|
| 写入事实数 | 10 条（水果/生日/学习/居住地/宠物/游戏/工作/会议/健身/咖啡） |
| Top-1 检索命中 | **10/10 = 100%** |
| 不存在事实误检 | 1 次（bigram"喜欢"造成噪声匹配，属 TF-IDF 小语料边界效应，可由 `RAG_MIN_SCORE` 抑制） |

### 3.4 角色一致性

| 维度 | 结果 |
|---|---|
| 5 种性格 prompt_fragment 区分度 | **5/5 = 100%**（温柔/活泼/傲娇/敏感/黏人 互不相同） |
| 5 种性格 TRAIT_MOTION 参数区分度 | **5/5 = 100%**（speed/amplitude/lean 全互异） |
| 性格切换护城河 | 新维度累计超主导 12 + 连续稳定 5 次才切 |
| 综合得分 | **100%** |

### 3.5 logit_bias 量化验证（此前已测得）

| 验证项 | 结果 |
|---|---|
| 离线断言 | **22/22 PASS**（公式正确性/上限钳制/有效地板/单调性/种子排除/选中增益/次级增益/条目截断/确定性/空输入） |
| 在线效应（可选 --live） | 量化目标 token 解码概率被抬高倍数（需 llama-server@8081） |

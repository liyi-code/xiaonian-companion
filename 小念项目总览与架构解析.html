小念（AI 桌面女友）项目总览与架构解析

本文档对「小念」项目做系统性总结，并给出三张图：架构图（分层模块职责）、数据流图（一次对话的完整链路）、思维导图（功能全景），每张图对每个功能点做详细解析。 覆盖范围：云端版 d:\AI训练\ai-girlfriend（DeepSeek LLM + GPT-SoVITS/字节 Seed-TTS + 智谱视觉 + 屏幕陪伴），以及本地版 d:\AI训练\ai-girlfriend-本地版（本地 Ollama + 意识层 clayer + RAG 长记忆压缩）。两套代码同源，差异以「【本地版差异】」标注。

一、项目一句话总结

小念是一个跑在桌面上的 AI 虚拟女友：用 tkinter 做窗口 + Live2D（Cubism）做会动的二次元形象，背后接大模型（云端 DeepSeek 或本地 Ollama）做对话，配语音输入（ASR）、语音输出（TTS + 实时口型）、屏幕陪伴（程序级 + 像素级视觉）、受约束自主权限（能"看着调"一些设置）、性格情感系统、长期记忆（RAG + 压缩）、意识层（多念竞争 + 价值选择，本地版独有）。所有功能围绕一个目标：让陪伴更自然、更个性化、更有"生命感"。

架构各层功能详细解析

1. 用户输入层（多入口）

小念不止"打字"一个入口：

  • 桌面输入框：GUI 文本输入，支持快捷按钮（🎤语音 / 📜历史 / ◐设置 / ↓控制台）。
  • 语音输入（ASR）：麦克风录音 → faster-whisper 转文字 → 进对话。VOICE_INPUT_ENABLED 总开关。
  • QQ / 微信 消息：account_qq.py / account_wechat.py 接入，把聊天消息当"另一渠道"的会话。
  • 屏幕事件：screen_watch.py 监听前台窗口变化（程序级感知），以及用户主动"看屏幕"触发像素级视觉。
  • 定时 / 自主触发：自主权限引擎（autonomy.py）空闲时主动关心、提醒休息；关心消息线程。

2. GUI 层（src/gui.py）

tkinter 主窗口，核心职责：

  • Live2D 渲染：用 webview 加载 assets/live2d/index.html，前端通过 WebSocket 与 Python 通信（live2d_say 下发气泡/动作/口型；setMouth 实时口型）；水印隐藏（Param191=1 每帧强制）。
  • 控制台面板：模型切换、API 设置（运行时热换）、语音开关、视觉设置、自主权限面板、意识层面板、软件更新、聊天历史。
  • 会话状态：App 持有 assistant，按渠道分 Session（桌面主人 / QQ / 微信），互不串台。
  • 语音链路编排：_start_sovits 启动 TTS 子进程；_speak 把 Live2D 气泡+动作对齐音频起点，播放回调实时算 RMS 经 socket 发口型，_stop_talk 归零。
  • 工具回调：on_tool 处理 LLM/路由工具结果（发消息回执、打开软件反馈、看屏描述、睡眠关闭）。
  • 模型加载提示：本地 Ollama 冷启动时显示"🧠 模型加载中"，就绪后提示发送（避免 2 分钟静默排队）。

3. 对话编排层（src/assistant.py · Assistant）

这是"大脑中枢"，一次对话的完整决策在此：

  • _route_action(text)：用正则识别明确动作意图（发消息/开软件/开网址/搜文件/系统状态/看屏幕/自主开关/睡眠），优先级高于 LLM，保证"说打开就真打开"。
  • _chat(user_text, ...)：主流程——用户发言先入记忆归档（供 RAG）→ 采集健康/习惯信号喂自主引擎 → 意识层 think（本地版）→ 检索增强召回旧片段 → 拼接 system 提示 → 调 LLM（流式 token）→ 后台触发记忆压缩 → 意识层 learn_async 回写。
  • system_prompt(mem)：注入人格设定、性格提示（由情绪累计派生）、主导情绪、健康底线（不迎合熬夜）、工具用法、屏幕陪伴说明。
  • Session：(平台, 用户) 维度隔离记忆与"待发送"状态，避免不同渠道串台。

4. 横向能力子系统

  • 记忆/检索（memory.py）：长期记忆归档 + 倒排索引 TF-IDF 检索 + 摘要压缩（本地版增强，详见第五节）。
  • 性格/情感（emotion.py）：5 维情绪短期波动 + 由情绪累计派生的"性格"（温柔/活泼/傲娇/敏感/黏人）；情绪只影响聊天话术与动作表情，不参与自主决策。
  • 自主权限（autonomy.py）：受约束自主——7 项白名单内可自调参，大调整弹窗确认，健康护栏（只往"更关心"方向），所有改动写 autonomy_overrides.json + 审计日志。
  • 工具层（tools.py + launcher.py + vision.py + screen_watch.py）：打开软件/网址、搜文件、系统状态、代发消息、创建文件、看屏幕、自主调参、记忆操作。
  • 意识层（clayer/，本地版独有）：详见第六节。

5. 外部能力层

所有重算力/网络都在外部，app 本身只发请求拿结果：

  • LLM：云端 DeepSeek（需 key）/ 本地 Ollama（11434，需本地模型）/ llama-server（8081，支持 logit_bias 真生效）。
  • TTS：GPT-SoVITS（本地子进程、克隆音色）/ 字节 Seed-TTS（云端 AI 音色，无 IP 隐患）。
  • ASR：faster-whisper 本地模型（国内镜像下载 model.bin）。
  • 视觉：智谱 GLM-4V（云端免费档）/ 本地 llama3.2-vision。
  • 屏幕/设备：PIL 截图、Windows 窗口枚举、声卡播放、麦克风录音。

三、完整数据流图（一次对话的端到端链路）

以下以本地版"普通对话 + 意识层 + RAG + 语音输出"为例，画出从用户敲字到小念"开口说话+动嘴型"的全链路，逐步解析。

[用户敲字/语音] 
   │
   ▼ ① GUI 采集文本（语音走 ASR→文字）
[App.send → Assistant.chat(user_text, on_tool, session)]
   │
   ├─② mem.add_message("user", ...)            # 用户发言入"归档"（仅归档，不进 recent）
   ├─③ _maybe_record_signals(user_text)         # 采集健康/习惯线索 → autonomy
   │
   ├─④ _route_action(user_text)                 # 确定性动作? → 走工具分支(见右)
   │      │ 否（普通对话）
   │      ▼
   ├─⑤ mind.think(user_text)  【本地版】        # 意识层：多念竞争→选主念+概率分布
   │      ├─ sleep_signal 判定（forced_sleep/sleepy_hint）
   │      ├─ compose_guidance(cl_state)          # 生成"让生活更美好"引导文本
   │      └─ build_logit_bias(cl_state)          # token 级偏置（仅 llama-server 生效）
   │
   ├─⑥ system_prompt(mem)                        # 人格+性格+情绪+健康底线+工具
   ├─⑦ mem.retrieve(user_text, k)   【本地版】   # RAG 检索增强：召回相关旧片段
   ├─⑧ messages = [system(+引导+回忆), history, user]
   │
   ├─⑨ _run_with_tools(messages, logit_bias=bias)  # 调 LLM（流式 on_token）
   │      ├─ 模型有 tools → 可能调 search_files/remember/look_at_screen...
   │      └─ 流式 token → on_token → GUI 边生成边显示
   │
   ├─⑩ _maybe_compress(mem)   【本地版】         # 后台线程：旧对话段→LLM 压缩成摘要
   ├─⑪ mind.learn_async(user_text, reply, cl_state)  # 后台回写联想网络（越聊越有倾向）
   │
   ├─⑫ mem.add_message("assistant", reply)       # 回复入记忆
   ├─⑬ _perceive_emotion(reply, source="self")  # 小念"自己说的话"→她自己的情绪波动
   │
   ▼ reply（文本）
[App._reply_one → 决定是否 TTS]
   │
   ├─⑭ _speak(reply)                             # Live2D 气泡 + 动作 + TTS
   │      ├─ live2d_say(气泡/动作) 对齐音频起点(on_play)
   │      ├─ TTS 合成（SoVITS/Seed-TTS）→ wav 字节
   │      ├─ play_wav_bytes：OutputStream 回调实时算 RMS
   │      ├─ 泵线程按 level_interval 发 on_level(rms) → socket → setMouth 口型
   │      └─ 结束 _stop_talk → {talk_stop} 归零嘴型
   │
   ▼ 用户看到：Live2D 说话 + 嘴动 + 气泡文字

数据流每个步骤详细解析

  • ① GUI 采集：App.send 拿到输入框文本（或语音经 ASR 转写），调用 assistant.chat。语音路径会先经 download_model.py 确保 model.bin 存在。
  • ② 记忆归档：mem.add_message("user", ..., to_history=False) 只写 memory_archive.jsonl（完整归档），不进 recent_history（recent 只存小念自己回复），修复了"用户发言不进记忆"的旧 bug，让 RAG 能检索到用户历史。
  • ③ 信号采集：_maybe_record_signals 用正则扫"熬夜/爆肝/久坐"等线索，喂给 autonomy.record_signal，供后续"更频繁提醒休息"等健康护栏。
  • ④ 确定性路由：_route_action 正则匹配——命中"打开/搜文件/看屏幕/发消息/睡眠"等直接走工具，不依赖模型是否"愿意调工具"（deepseek 常"说说不调"）。命中则跳到工具分支、不经 LLM。
  • ⑤ 意识层 think【本地版】：mind.think 跑扩散激活联想网络，输出 ConsciousState（主念 chosen / 概率分布 distribution / 睡眠信号 / 注意力）。异常自动降级为"原逻辑"。
  • ⑥ 系统提示：system_prompt 注入人格、由 emotion 提供的性格/情绪提示、健康底线（绝不迎合熬夜）、屏幕陪伴说明、工具用法。
  • ⑦ RAG 检索：mem.retrieve 用 TF-IDF（bigram 满权/单字降权，低于 RAG_MIN_SCORE 视为噪声）召回相关旧片段 + 加权摘要，注入 system 的【相关回忆】段，削弱幻觉、保持连贯。
  • ⑧ 组装 messages：引导文本（若有）拼到 system 后，再加 RAG 回忆、recent_history、当前用户消息。
  • ⑨ LLM 生成：_run_with_tools 调 OpenAI 兼容接口（流式）。模型可能调用 tools.py 里的函数（搜文件/记记忆/看屏幕），结果经 on_tool 回传 GUI。流式 token 经 on_token 实时上屏。若模型不支持 tools，退化纯对话。
  • ⑩ 记忆压缩【本地版】：_maybe_compress 在用户空闲时，把未压缩旧对话段用 LLM 总结成长期记忆要点（add_summary），避免无限堆长上下文、前后矛盾。按 id 空间推进指针（修复过"只压一次"bug）。
  • ⑪ 意识层学习【本地版】：mind.learn_async 后台把本次对话回写联想网络（含用户概念、选中概念），使小念"越聊越有自己的倾向"。think/consolidate 会先 join 它保证一致。
  • ⑫ 回复入记忆：mem.add_message("assistant", reply) 让 recent_history 滚动。
  • ⑬ 情绪感知：_perceive_emotion(reply, "self") 解析小念自己说的话里的情绪词 → 她自己的情绪涨落（玩家输入只诱导、不直接决定她的情绪）。
  • ⑭ 语音输出：_speak 编排 Live2D 气泡+动作与 TTS 对齐；TTS 合成 wav 后经 play_wav_bytes 的 OutputStream 回调实时算 RMS，泵线程发 on_level → 前端 setMouth 实时口型，结束归零。

思维导图各分支详细解析

1. 形象与交互：Live2D 是"脸面"。水印隐藏用 Param191=1 每帧强制（因 coreModel 无 getParameterCount，旧方案失效）。多形象切换靠 LIVE2D_MODEL 配置。性格影响动作选择（傲娇少跳、黏人多黏）。快捷键让用户不离开当前窗口也能操控小念。

2. 对话大脑：LLM 是"脑子"。支持运行时换 API（不用重启，面板填好热替换客户端并写回 .env）。流式生成让回复即时上屏。确定性路由保证"说打开就真打开"，弥补 deepseek 不主动调工具的缺陷。多 Session 让桌面/QQ/微信三个渠道记忆互不串。

3. 记忆与个性化：这是"长期关系"的核心。RAG 让小念记得你说过的话（削弱幻觉），压缩让记忆可长期保存而不爆上下文。性格由情绪累计派生（温柔/活泼/傲娇/敏感/黏人），情绪只影响话术与表情、不参与自主决策（职责分离）。健康底线写死在 system_prompt：不迎合熬夜。

4. 语音链路：ASR 用本地 faster-whisper（国内镜像 hf-mirror.com 下 model.bin）。TTS 云端版用 Seed-TTS 5 种 AI 音色（无克隆 IP 隐患），本地版用 GPT-SoVITS。实时口型关键 bug 已修：初版用 time.time() 预计算能量时间轴与声卡漂移→句尾嘴停，改为播放回调取当前片 RMS 实时发，严格对齐实际播放。

5. 屏幕陪伴：分两层——程序级（窗口标题/进程名，知道你在干嘛）与像素级（视觉模型真看懂画面）。两者层次不同，升级是"程序级→画面级"。看屏时即使关闭截屏也会自动现截。

6. 自主与工具：自主权限严格受约束——7 项白名单、大调整确认、健康护栏、审计备份。工具层让小念能"动手"：代发消息、开软件、搜文件、建文档（带系统目录护栏防误删）。

7. 意识层【本地版独有】：本地版最强差异点。多念竞争 + 价值选择让小念"有自己的想法"；睡眠机制让联想网络在超阈值时压缩整合（自愈"越聊越慢"）；build_logit_bias 把价值偏好转成 token 级偏置（已量化验证 22/22）。C++ 加速热数学、Python 回退保证可用。

8. 工程与部署：通用化让项目"换电脑直接跑"（路径相对项目根、设备自动探测）。一键启动自举 venv/.env/模型。自动更新用 git-free updater，双保险不碰个人数据（.env/data/models）。睡眠关机让小念"下班"时先整理记忆再优雅退出。

# 小念 · AI 挚友（本地版）

> 一个会**记住你、主动关心你、还会自己"想事情"**的桌面 AI 伴侣。

小念不是"一问一答的聊天机器人"。她在本地大模型之上，外挂了一层**意识层**——会联想、会遗忘、会睡眠时"做梦"、会从记忆里自己找出话题主动来找你聊。她记得你说过的话，会看你的脸色，也会在你说"让我一个人待会儿"时安静退下。

**全部数据留在你自己的电脑上**，不开源你的记忆，不上传云端（除非你主动配置）。

## 🎯 它到底特别在哪？

大多数 AI 陪聊，只是"模型 + 皮肤"。小念多了三样东西：

| 别人没有的 | 小念有 |
|-----------|--------|
| **会联想、会遗忘的"意识流"** | 外挂意识层（clayer），在解码侧用 `logit_bias` 硬偏置，让回复真的带上"自己在想事情"的连续感 |
| **会"做梦"的睡眠机制** | 睡着时两条通路并行：语义压缩 + **创新组合**（把记忆碰撞成新点子），卡壳时回查这些"梦到的灵感"换角度想 |
| **会自己找话题的主动性** | 从睡眠成果里挑种子主动搭话，**零大模型成本**，你乐意聊才启动 LLM，你烦了它"知错就改" |

> 一句话：**她不只是"会说话"，而是"像在生活"**——有记忆、有情绪、有性格、会做梦、会看脸色。

## ✨ 功能特性

### 🧠 像人一样"想"

- **意识层（clayer）**：模拟联想 / 注意力 / 遗忘 / 价值导向，越聊越有"自己在想事情"的连续意识流
- **双通路睡眠 + 想象力出口**：睡眠时"做梦"——把高权重概念碰撞成新点子，表层想不出答案时回查这些灵感
- **主动找话题（零 LLM 成本）**：从睡眠成果挑种子主动搭话，绝不随机、绝不抓网
- **检索增强记忆（RAG）+ 长对话压缩**：聊再久也不丢上下文、不前后矛盾

### 💃 像人一样"动"

- **Live2D 形象**：官方免费可商用模型 hiyori_pro，实时口型、表情、动作
- **Unity 3D 形象（程序化动画）**：呼吸/挥手/点头/环顾/转身，带阻尼平滑，不依赖外部动画师
- **性格 × 情感驱动动作**：5 种性格（温柔/活泼/傲娇/敏感/黏人）× 5 维情绪，**动作速度、幅度、身体倾向、招牌小动作都由"当下情绪×性格"实时融合**

### 💗 像人一样"陪你"

- **屏幕陪伴 + 多模态视觉**：感知你在用什么软件，甚至"看懂"屏幕画面
- **主动关心 + 受约束自主权限**：只在白名单内自调参（如更频繁提醒休息），绝不碰系统/代码/你的文件
- **数据 + 截屏联合理**：程序级（窗口/进程）+ 像素级（视觉模型）双通道感知
- **网络搜索 + 自主学习**：遇到不会的事自动上网搜索，用搜索到的知识指导下一步
- **帮你操作电脑**：开软件、搜文件、建计划/笔记
- **可选语音**：本地 GPT-SoVITS 克隆音色（默认关）

## 🚀 快速开始（本地 Ollama）

1. **装 Ollama** 并拉模型（推荐，约 9GB）：
   ```bash
   ollama pull qwen2.5:14b
   ```
   > 备选：`deepseek-r1:32b`（更强更慢）、`qwen2.5:7b`（轻量）。
   > 想常驻内存避免冷加载，设环境变量 `OLLAMA_KEEP_ALIVE=-1`（重启 Ollama 生效）。

2. **装 Python 3.10+**（勾选 "Add python.exe to PATH"）。

3. **拉仓库**：
   ```bash
   git clone https://github.com/liyi-code/xiaonian-companion.git
   cd xiaonian-companion
   ```

4. **双击 `启动.bat`** — 首次自动建 venv、装依赖、生成 `.env`。

5. **再双击一次**，开始聊天。

> ⏳ 首次发消息会冷加载模型（十几秒到一两分钟），加载完常驻内存，之后秒回。
> 也可点输入条 `◐` → 「API 设置」换模型 / 换云端 API。

## 🧠 意识层（clayer）——她为什么"像在想"

小念的"脑子"不是只靠 qwen 一句话生成。我们在 qwen **外挂一层意识层**（`src/clayer/`）：**不改模型权重、不微调、不量化**，只作为认知框架，在「输入侧联想引导 + 解码侧 logit_bias 硬偏置」两头调制 qwen。

### 两条接入点

1. **提示词软引导**：对话前跑一次意识活动，把并联浮现的多道"意念"（主念/副念 + 情绪 + 价值导向）拼进 system prompt。
2. **解码硬偏置（关键）**：意识层算出的概念概率 `P(c)` 编译成 `logit_bias = GAIN · P(c)^γ`，直接抬高被联想唤醒的 token——主念额外 boost，已有种子词不偏置。
3. **动态逐段偏置**：长回复切 ~48 token 一段，每段重跑一次意识活动，用刚说的话当新种子，模拟"边说边想"。

### 一次意识活动的流程

```
感知(显著度加权) → 种子带能量 → 沿关联链多跳扩散激活(≤4跳、能量衰减、阈值截断)
   → softmax 成概率(下限0.02防独裁 / 上限0.55防僵化)
   → 最多4道并行"意念"互相抑制、按 vigor 竞争注意力(主念胜出)
   → 熵映射到 qwen 的温度 / top_p
```

### 模块组成（`src/clayer/`）

| 模块 | 职责 |
|------|------|
| `consciousness.py` | 总编排：`think()` / `learn()` / `consolidate_memory()` |
| `assoc_graph.py` | 关联图：扩散激活、Jaccard 相似度、遗忘衰减、consolidate |
| `probability.py` | 概率引擎：分布构建 / 温度与熵调制 |
| `token_bias.py` | 概率分布 → `logit_bias`，直接介入 qwen 每步解码 |
| `memory_store.py` | 概念计数、显著度、容量淘汰 |
| `perception.py` | 分词（jieba 优先，回退 CJK 单字 + bigram） |
| `affect.py` | 情绪（效价-唤醒二维）+ 注意力 softmax |
| `sleep.py` | 双通路睡眠：通路二「创新组合」+ 想象力出口 |
| `topic.py` | 主动找话题：从睡眠成果挑种子，纯规则零 LLM 成本 |
| `cl_config.py` | 全部常量，**每项带神经科学文献出处** |

### 底层"判断标准"（元目标）

意识层内置 `WELLBEING` 价值词库：命中"成长/健康/早睡/自律…"得正分，命中"熬夜/拖延/摆烂…"得负分。价值分作为竞争力第四轴，让输出天然偏向**"让使用者的生活越来越好"**——即使某念头再强，只要拉低生活品质就会被压下去。

### 工程亮点

- **C++ 加速 + 纯 Python 回退**：启动做数值 parity 自检（容差 1e-9），不一致自动降级；换机器、没编译也能跑。
- **常量有科学依据**：储存量 42000（Brysbaert 2016）、注意力焦点 4±1（Cowan 2001）、语义网小世界路径 3-4 跳（Steyvers & Tenenbaum 2005）等。
- **性能自愈**：遍历 >450ms 犯困、>500ms 强制睡眠压缩，治"越聊越慢"。

## 💭 双通路睡眠与想象力出口

小念"睡着"时，两条通路并行处理当天记忆：

- **通路一 · 语义压缩**：把快归零的弱词并入最强相关词，降遍历耗时。
- **通路二 · 创新组合**：把高权重概念随机碰撞成"合成概念"，新权重 = 成员权重之和，存独立索引。

两类产物**可相互关联**（弱连接）。表层想不出答案时，回查合成概念索引作**想象力出口**，把"梦到的灵感"交给 LLM 换个角度想。

**边际效用（slope_utility）— 驯化而非预测**：每个组合记录最近 N 次使用时的状态斜率。用了之后你更开心 → 效用正、保留强化；更难过 → 效用负、下次丢弃。

> 安全边界：合成概念存独立索引不污染主图；`DUAL_PATHWAY_ENABLED=False` 一键回退；起步保守（阈值 0.8、二元组合、单次上限 12）。

## 💬 主动找话题（零 LLM 成本）

小念的灵感全来自**睡眠成果**，绝不随机、绝不临时抓网。

- **来源 A · 创新组合**：`combos.json` 里"刚生成、效用高、还没用过"的合成概念。
- **来源 B · 遗忘预警**：正在快速衰减、但曾被反复提到的高频词——在忘掉前帮你抢救。

**触发（状态机，不空转）**：① 空闲 ≥5 分钟 ② 非勿扰/专注 ③ 距上次 ≥2 小时，三者同时满足才触发。可说 *"让我一个人安静一会儿"* 静默 1 小时，Live2D 输入条也有「状态」按钮。

**零成本策略**：第一步纯规则套话术（不调 LLM）；只有你回复后才启动 LLM 续聊。

**「越来越」闭环**：你乐意聊 → 种子加权；你无视或骂"滚" → 拉黑种子 + 缩短下次间隔（"看脸色、知错就改"）。

## 💞 性格与情感如何驱动动作

她的肢体风格由**情绪 × 性格**两层实时融合：

| 性格 | 动作风格 | 身体倾向 | 招牌小动作 |
|---|---|---|---|
| 活泼开心 | 轻快、幅度大 | 略前倾 | 爱挥手 |
| 黏人紧张 | 中等速度 | 明显前倾（靠近） | 跟随/靠近 |
| 傲娇小脾气 | 略快、小幅甩动 | 后缩（别过脸） | 偶尔转身 |
| 敏感爱哭 | 最慢、最小幅 | 明显后缩、低头 | — |
| 温柔平静 | 舒缓、克制 | 中性略后 | — |

```
对话/事件 → emotion.motion_params() → bridge.compute_action_params()（融合 joy×性格）
   → WebSocket action 事件 → NpcBridgeClient → ConceptStateMachine.TriggerAction
   → Unity 角色演出带"性格"的肢体语言
```

> 性格只改演出风格，永远不改变底层目的（让使用者生活越来越好）。

## ❓ 常见问题

- **首次回复很慢？** 本地模型冷加载中，设 `OLLAMA_KEEP_ALIVE=-1` 常驻后秒回。
- **想换模型？** 改 `.env` 的 `MODEL` 或点输入条 `◐`。
- **没有 GPU？** 可用 CPU 跑（较慢），语音设备自动探测。
- **不要提交 `.env`！** 含密钥，已被 `.gitignore` 忽略，分享用 `.env.example`。
